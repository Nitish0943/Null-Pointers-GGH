# Implementation roadmap

1. Confirm product requirements, roles, data ownership, and threat model.
2. Define shared domain types and validation contracts.
3. Implement and test Firebase authentication, authorization, rules, and
   audited trusted functions.
4. Build web and mobile vertical slices against shared contracts.
5. Add offline synchronization with conflict and recovery behavior.
6. Add AI integrations behind validated server-side boundaries.
7. Add end-to-end, accessibility, security, and release verification.

All listed product functionality is not implemented at the current phase.
